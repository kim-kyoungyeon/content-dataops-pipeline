# 0004. 문항 출처 규칙

status: accepted

## 배경
공개 레포에 문항을 올리므로 저작권과 출처가 분명해야 한다.

## 결정
문항은 직접 제작(`source: self`)하거나 승인된 synthetic(`source: synthetic`)만 쓴다. synthetic은 `review.status: approved`와 검수자(`review.by`) 기록이 있어야 한다. 상업 교재, 회사 문항, 시험 원문은 레포에 넣지 않고 메타데이터와 링크만 둔다.

## 이유
공개 레포에서 권리 문제를 피하고, 생성 문항의 품질 책임을 검수 기록으로 남긴다.

## 대안
변형 문항 허용. 원문과의 경계가 모호해 채택하지 않았다.
