# 0003. 시제를 독립 노드로 둔다

status: accepted

## 배경
초기 설계에서는 학생이 시제를 이미 안다고 보고 별도 노드를 두지 않았다.

## 결정
시제를 독립 노드 `verb.tense`로 둔다. 위치는 3단 변화(`verb.inflection`) 다음, 조동사(`verb.modal`) 앞이다. 시제는 to부정사, 분사, 가정법의 선수 노드다.

## 이유
to부정사의 완료형, 분사구문의 시제, 가정법의 시제 이동은 시제를 모르면 설명이 안 된다. 안다고 가정하면 뒤쪽 노드에서 막히는 지점이 생긴다.

## 대안
시제를 다른 노드 안에 흩어 설명. 선수관계가 그래프에 드러나지 않아 채택하지 않았다.
