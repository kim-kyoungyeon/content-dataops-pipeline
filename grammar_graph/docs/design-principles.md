# 설계 원칙 (가설)

아래는 검증 전 가설이며 근거는 현장 관찰(일화)이다. 모두 [ADR 0005 타깃 학습자](decisions/0005-target-learner.md)에서 파생되었다. 검증되면 ADR로 옮기고 status를 바꾼다.

허용 status: proposed, accepted, superseded.

## 0006. 진도 숨김
status: proposed

학생 화면에는 그래프와 전체 진도를 숨기고 남은 시간만 보여 준다. 전체 분량이 보이면 시작 전에 포기하는 경우가 있다는 관찰에서 나왔다.

- 반증 가능성/검증 방법: 진도 공개 그룹과 숨김 그룹의 세션 완료율, 다음 세션 재방문율 비교.

## 0007. 표현을 바꾼 반복
status: proposed

같은 개념을 정석 설명, 단순화한 설명, 도식·아이콘 순으로 반복한다.

- 반증 가능성/검증 방법: 같은 표현 반복 대비 재풀이 정답률 비교.

## 0008. 짧은 노드, 적은 문항, 잦은 반복
status: proposed

노드를 짧게 나누고 한 번에 푸는 문항 수를 줄이는 대신 간격을 두고 자주 반복한다(간격 반복).

- 반증 가능성/검증 방법: 한 번에 몰아서 푸는 방식 대비 일정 기간 뒤 재풀이 정답률과 완료율 비교.

## 0009. 오답 시 템플릿 카드와 쉬운 유사 문항
status: proposed

틀리면 템플릿 카드와 더 쉬운 유사 문항을 준다. 같은 문항을 틀린 횟수에 따라 카드를 달리 보여 준다(1회 정석, 2회 단순화, 3회 도식).

- 반증 가능성/검증 방법: 카드 제공 여부에 따른 유사 문항 정답률과 같은 노드 재오답률 비교.

## 0010. 암기 단계와 확장 단계 분리
status: proposed

노드를 암기(memorize)와 확장(expand) 단계로 나눈다. 암기가 끝나야 확장 문항을 연다.

- 반증 가능성/검증 방법: 단계 분리 여부에 따른 확장 문항 정답률과 이탈률 비교.

## 0011. 집중력 저하 신호 감지 시 쉬운 문제나 휴식
status: proposed

응답 시간이 급격히 늘거나 연속 오답이 나오면 쉬운 문제나 휴식을 제안한다.

- 반증 가능성/검증 방법: 개입 여부에 따른 이후 문항 정답률과 세션 완료율 비교. 신호의 오탐률도 함께 기록.
