# 설계 원칙 (가설)

> 구현 상태: 아직 없음. 이 문서는 학습자 앱 단계의 요구사항 가설이며, 현재 레포(그래프, 문항, CI)에는 학습자 추적 코드가 없다.

아래는 검증 전 가설이다. 근거는 주로 현장 관찰(일화)이고, 일부(H-0006)에는 연구 근거를 덧붙였다. 대상 학습자는 [ADR 0006](decisions/0006-target-learner-expanded.md)을 따른다(ADR 0005는 superseded).

번호 체계: 가설은 `H-NNNN`, 결정은 ADR `NNNN`으로 번호 공간이 서로 다르다. 가설이 검증되면 새 ADR 번호를 받고, ADR의 배경에 원래 가설 번호를 적는다.

허용 status: proposed, accepted, superseded.

## 검증 방식과 폐기 기준 (공통)

### 참가자와 설계
- 소규모 학생 참가자(초기 3명)로 검증한다.
- 설계자 본인의 테스트는 사용성 점검(dogfooding)으로만 쓰고 근거로 쓰지 않는다.
- 인원이 적으므로 그룹 간 비교 대신 학생별 단일 사례 설계(ABAB, 조건을 번갈아 적용하는 반전 설계)를 쓴다. 3명에게 같은 설계를 적용하면 같은 검증을 3번 복제하는 셈이다.
- 한계(이월 효과): 학습이 쌓이는 조건(H-0007, H-0008)은 OFF 기간에도 앞선 ON 기간의 효과가 남을 수 있다. 결과를 해석할 때 감안한다.
- 규모가 커지면 층화 무작위 배정을 쓴다. 수준별로 묶은 뒤 각 묶음 안에서 무작위로 나눈다. 대규모에서는 단순 무작위도 가능하다.

### 라운드 정의
- 라운드: 조건 적용 기간(ON) 1개와 미적용 기간(OFF) 1개의 쌍.
- 기간 단위: 평일 5일. 판단은 5일 누적 학습 데이터로 한다. 일 단위 데이터는 변동이 커서 방향 판단에 쓰지 않는다.
- 주말은 접속률이 낮을 것이라는 가정이므로 비교 데이터에서 제외한다. 이 가정은 접속 로그로 먼저 확인한다(확인 전에는 가정).
- 예: 첫 주 평일 ON, 다음 주 평일 OFF, 그다음 주 평일 ON, 그다음 주 평일 OFF = 2라운드. ON과 OFF 사이의 주말이 자연스러운 휴지기가 된다.
- 기간을 짧게 잡는 이유: 틀린 가설을 오래 적용하면 학생에게 지루함과 UX 저하를 주기 때문이다.

### 폐기 기준
- B. 방향 기준: 두 라운드 연속 ON 기간 결과가 OFF 기간보다 나쁘면 해당 가설을 폐기(superseded)하고 대안 가설을 새로 제안한다.
- C. 위해 기준: 주 지표가 좋아져도 아래 신호가 나타나면 즉시 중단하고 재검토한다.
  - 주 트리거(행동 신호, 질문 없이 수집): 세션 중도 이탈, 건너뛰기 증가, 비정상적으로 빠른 무작위 응답, 결석 증가.
  - 보조 확인(자기 보고): 챕터 종료 시 1탭 만족도(좋음/보통/싫음). 매 세션 묻지 않는다(피로와 무성의 응답 방지).
- 미성년자 대상 데이터 수집 전 동의 고지(필요 시 보호자 동의)를 확인한다.

## H-0006. 진행 중 진도 숨김, 챕터 종료 시 공개
status: proposed

세션 중에는 그래프와 전체 진도를 숨기고 남은 시간(time limit)만 보여 준다. 한 챕터가 끝나면 전체 진도와 그래프(branch)를 보상처럼 보여 준다. 학생이 중간에 종료해도 그 시점까지의 진도를 보여 준다.

- 근거(현장): 다음 분량을 보며 언제 끝날지 가늠하다가 포기하는 학생이 있었다.
- 근거(연구): Villar, Callegaro, Yang(2013) 메타분석(무작위 실험 32건)에서 고정 진도 표시는 이탈 감소 효과가 유의하지 않았다. 초반이 빠른 표시는 이탈을 줄였고, 초반이 느린 표시는 이탈을 늘렸다. 문법 학습은 초반 진도가 느리므로 실시간 진도 표시는 불리할 수 있다.
- 한계: 웹 설문 연구라 학습 앱에 그대로 적용되는지는 검증되지 않았다.
- 검증: 진행 중 진도 공개(ON)와 숨김(OFF)을 번갈아 적용해 세션 완료율과 재방문율 비교.
- 폐기 조건: 공통 기준 B, C.

## H-0007. 표현을 바꾼 반복
status: proposed

같은 개념을 정석 설명, 단순화한 설명, 도식·아이콘 순으로 반복한다.

- 검증: 같은 표현 반복 대비 재풀이 정답률 비교.
- 폐기 조건: 두 라운드 연속 표현 변경 구간의 재풀이 정답률이 같은 표현 반복 구간보다 낮다.

## H-0008. 짧은 노드, 적은 문항, 간격 반복 인출
status: proposed

노드를 짧게 나누고 한 번에 푸는 문항 수를 줄인다. 간격을 두고 반복 인출한다. 반복은 템플릿을 다시 보여 주는 노출이 아니라, 학생이 직접 떠올리게 하는 인출이다(빈칸 채우기, 카드가 보이기 전에 먼저 답하기). 근거는 시험 효과(testing effect)다.

### H-0008-a. 기본 조건 (모든 학습자)
대상: 집중력과 인내심이 부족한 학습자, 그리고 성실하지만 실력이 부족한 수동형 학습자(출석·숙제 완료에만 의의를 두는 유형).
- 빠른 템포, 적은 분량, 잦은 템플릿 반복 인출을 기본값으로 쓴다.
- 분량이 많으면 부담으로 이탈할 가능성이 높으므로 한 번의 분량을 작게 유지한다.
- 반복은 의무로 둔다.
- 검증: 몰아 풀기 대비 일정 기간 뒤 재풀이 정답률과 완료율 비교.
- 폐기 조건: 두 라운드 연속 몰아 풀기보다 낮다.

### H-0008-b. 반복 축소 조건 (고성취 학습자)
대상 범위는 [ADR 0006](decisions/0006-target-learner-expanded.md)에서 확장되었다(고성취 학습자도 같은 목표의 대상이며, 이탈하지 않게 하는 것도 설계 목표).

진입 조건 두 가지를 모두 만족해야 한다.
- 필수(숙달): 습득한 노드의 간격 재풀이 정답률이 기준값(예: 80%) 이상
- 보조(성실): 매일 출석하고, 일정한 문항 수나 시간을 지키며, 노드 완료 추이가 우상향

진입하면 반복 간격을 늘리고 다음 노드로 진행한다. 필수 조건 아래로 떨어지면 H-0008-a로 되돌린다. 성실만 충족하고 숙달이 부족한 학습자는 H-0008-a에 둔다.
- 검증: 같은 학습자의 반복 축소 구간과 고정 반복 구간의 재풀이 정답률 비교(ABAB).
- 폐기 조건: 두 라운드 연속 반복 축소 구간의 정답률이 더 낮다.

## H-0009. 오답 시 템플릿 카드와 쉬운 유사 문항
status: proposed

틀리면 템플릿 카드와 더 쉬운 유사 문항을 준다. 같은 문항을 틀린 횟수에 따라 카드를 달리 보여 준다(1회 정석, 2회 단순화, 3회 도식). 표현 순서는 H-0007을 따른다.

- 검증: 카드 제공 여부에 따른 유사 문항 정답률과 같은 노드 재오답률 비교.
- 폐기 조건: 두 라운드 연속 카드 제공 구간의 재오답률이 미제공 구간보다 높다.

## H-0010. 암기 단계와 확장 단계 분리
status: proposed

노드를 암기(memorize)와 확장(expand) 단계로 나눈다. 암기가 끝나야 확장 문항을 연다. 암기 대상은 최소한으로 템플릿화한다.

- 검증: 단계 분리 여부에 따른 확장 문항 정답률과 이탈률 비교.
- 폐기 조건: 단계 분리 구간에서 이탈률이 높아지고 확장 정답률 이득이 없다.

## H-0011. 집중력 저하 신호 시 저부하 참여로 전환
status: proposed

응답 시간이 급격히 늘거나 연속 오답이 나오면 학습을 멈추지 않고 부하가 낮은 참여로 전환한다. 예: 수동적 시청(도식·설명 보기), 가장 쉬운 객관식, 단어 10개 맞히기. 목적은 이탈 없이 학습 흐름을 유지하는 것이다.

- 검증: 전환 여부에 따른 이후 문항 정답률과 세션 완료율 비교.
- 신호 오탐률: 학생별 기준 응답 시간 대비로 측정해 기록한다.
- 폐기 조건: 저부하 구간에서 건너뛰기나 무작위 응답이 늘어나거나, 전환 후 완료율이 두 라운드 연속 낮다.

## H-0012. 이탈 방지와 학습 방식 강제의 분리
status: proposed

참여를 강제하는 장치를 두 종류로 나눠 따로 검증한다.
- 이탈 방지: 세션을 끝까지 하게 하는 장치(H-0006 진도 숨김, H-0011 저부하 전환, H-0013 포인트와 뱃지).
- 학습 방식 강제: 정해진 방식으로 공부하게 하는 장치(H-0009 템플릿 카드, H-0010 암기 게이트, H-0008 반복 인출).

- 검증: 이탈 방지는 완료율로, 학습 방식 강제는 재풀이 정답률로 따로 본다.
- 폐기 조건: 완료율은 올랐는데 정답률이 그대로이거나 떨어지면, 해당 장치는 학습 효과가 없는 것으로 보고 재설계한다.

## H-0013. 포인트 가중치와 뱃지
status: proposed

### 포인트
- 가중치는 난이도와 정확도로 준다. 시간이나 참여만으로는 주지 않는다(저부하 구간 포인트 파밍 방지).
- 초기 적응 기간(golden period)에는 문항당 1.0을 준다. 익숙한 구간(예: 동사 파트 완료 후)부터 0.5~0.3, 지나치게 쉬운 문항은 0.1을 준다.
- 적응 기간 종료 시점은 시간이 아니라 노드 완료로 정한다. 느린 학습자는 적응 기간이 길어진다.
- 노드별 가중치 값과 하락 규칙은 학생에게 공개하지 않는다.
- 화면에는 게임의 HP 바처럼 노드나 단계가 끝날 때마다 차오르는 막대를 보여 준다. 이 막대는 세션 목표치 대비 채움이며 전체 진도 척도와는 별개다. 학생은 막대가 줄어들거나 덜 차는 것을 볼 수 있다.

### 뱃지
- 챕터나 목표를 마치면 수집형 뱃지를 준다.
- 뱃지는 아이템으로 쓸 수 있다. 막대가 줄어드는 것(포인트 누적 하락)을 막거나, 일정 기간 적응 기간 혜택을 다시 받는 데 쓴다. 막대가 화면에 보이므로 학생은 무엇을 막는지 바로 알 수 있다.
- 사용 횟수에 상한을 둔다(뱃지로 노력을 대체하는 회피 방지).

### 검증과 폐기
- 검증: 포인트·뱃지 적용 구간과 미적용 구간의 세션 완료율, 재방문율 비교.
- 폐기 조건: 공통 기준 B, C. 추가로 포인트 획득은 늘었는데 재풀이 정답률이 그대로이면 보상이 학습과 분리된 것으로 보고 재설계한다.
- 위험: 외적 보상이 끊기면 행동도 끊길 수 있다(과잉정당화 효과). 이 연령대에서의 강도는 확인되지 않았다.
- 위험: 막대의 채움으로 진도를 어림잡을 수 있어 H-0006(진행 중 진도 숨김)의 효과가 약해질 수 있다. H-0006과 H-0013을 함께 적용할 때의 이탈률도 따로 확인한다.

## 확장 단계 메모 (가설 아님)
- 유료 콘텐츠: 어휘·어법을 교양 방식으로 풀어 주는 숏폼 영상과 강의. 포인트 사용처 후보. 오픈소스 무료 범위와의 경계는 별도로 결정한다.
