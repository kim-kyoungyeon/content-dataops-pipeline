# sample_data

`sample_input.xlsx`는 `tools/make_sample.py`가 고정 시드로 만든 **가상 데이터**입니다.

- 모든 값은 가상입니다. 도시명(가람시·누리시·다솜시·라온시), 법령명(`OO시 도시계획 예시조례`), 조항 문구, 기준값, 수정값, 등급은 이 스크립트가 만든 것이며 실제 지자체나 조례를 인용하지 않습니다.
- 등급 규칙은 이 프로젝트 자체 예시이며, 실제 기관이나 회사의 기준이 아닙니다.

## 등급 규칙

`등급판단 데이터` = 가상 충족률(%) = round(가상 실측값 / 가상 기준값 × 100)

| 충족률 | 등급 |
|--------|------|
| 100 이상 | A |
| 80 이상 | B |
| 60 이상 | C |
| 60 미만 | D |

## 행 구성

20행(가상 도시 4곳 × 항목 `1-1`~`1-5`)이며, 행마다 시나리오 하나를 넣어 파이프라인의 모든 경로를 지나가게 했습니다.

- 표준화: `이상 없음`, `정상`, `확인 필요`, `별표 참조`, `조례 변경` 같은 표기 변형
- 플래그: EMPTY_DE, WEAK_E, AMBIG, ATTACH, LAW_FIX, NUM_FIX(`20->25` 형식과 `수치변경`), ETC, OK
- 자동 채움: D·E가 비어 있고 AI 추출 열(`조항내용.1`)이 충분히 긴 2행 → `AI조항복붙`(AI_FILLED)

기본 실행 결과: 20행 처리, 13행 플래그(OK 7행 제외), 자동 채움 2행. `--range 1-1 1-3`은 12행 중 6행 플래그입니다.

## 다시 만들기

```bash
python tools/make_sample.py
```

`tests/test_sample_data.py`가 커밋된 파일과 스크립트 출력의 셀 값이 같은지 검사합니다. 스크립트를 바꾸면 위 명령으로 파일을 다시 만들어 함께 커밋하세요.
